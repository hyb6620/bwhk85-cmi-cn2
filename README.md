## 搬瓦工 HK85 是什么

HK85 是搬瓦工香港 VPS 社区里使用较多的简称。第三方资料通常把它对应到香港 CMI 机房，也有资料使用 `HKHK_3` 这个标识。历史测试中，这款方案常见配置为：

- 2 个虚拟 CPU
- 2 GB 内存
- 40 GB SSD 或 RAID-10 SSD
- 每月 1 TB 流量
- 2.5 Gbps 端口
- 香港机房
- IPv4 地址
- KVM 虚拟化与 KiwiVM 控制面板

需要注意的是，`2.5 Gbps` 是端口上限，不代表单个用户可以长期跑满。VPS 的实际速度还会受到 CPU、磁盘、共享节点、目标网络、运营商方向和高峰期拥塞影响。

过去的 HK85 测试资料里，香港 CMI 方案通常表现为三网回程经过中国移动国际网络，移动用户往往更容易获得较低延迟；电信和联通则可能出现去程绕日本、回程走 CMI 的情况。第三方测试曾记录到香港本地低延迟、部分中国大陆节点延迟较低，但不同运营商和地区之间差异明显。

这也是 HK85 评价容易两极分化的原因：移动用户看到的结果可能不错，电信用户在某些地区也能正常使用，但不能简单概括成“三网都一样快”。

## HK85 的线路表现：CMI 和 CN2 GIA 不是一回事

很多搬瓦工香港 VPS 文章会把“香港”“低延迟”“三网回程”放在一起，读者很容易误以为所有香港套餐都使用 CN2 GIA。实际上，线路名称要单独看。

### HK85：更接近香港 CMI 方案

历史资料对 HK85 的描述大多指向 CMI，也就是 China Mobile International。常见路由特点可以概括为：

- 中国移动用户：通常更容易获得直接或较顺畅的连接；
- 中国联通用户：可能经过日本或其他国际转接；
- 中国电信用户：不同地区差异较大，不能只看香港到中国大陆的地理距离；
- 晚高峰表现：可能受到 CMI 国际段拥塞影响；
- 线路性质：不能按三网 CN2 GIA 套餐理解。

第三方测试还显示，HK85 这类机房的网络质量并不是唯一变量。即使同一个机房，测试时间、出口 IP、目标城市和本地宽带运营商不同，也可能得到不同结果。某次测试中，移动方向的速度和延迟表现相对突出，而联通、电信方向则有更明显的波动。

## HK85 性能测评：配置够做什么

按照历史公开测试资料，HK85 常见配置为 2 核 CPU、2 GB 内存、40 GB SSD 和 1 TB 月流量。第三方测试中，CPU 单核大约在 500 分上下，多核大约在 1,000 分左右，磁盘顺序读写表现尚可，但 4K 小文件性能不会达到独立服务器级别。

这类配置适合：

- 个人博客；
- 小型企业展示站；
- 轻量级 API；
- 开发测试环境；
- 反向代理或跳板用途；
- 低流量的海外网站；
- 需要香港节点做联通性测试的项目。

不太适合：

- 高访问量 WordPress；
- 大量图片、视频或下载文件；
- 数据库写入频繁的业务；
- 长时间运行编译、爬虫或批处理任务；
- 多人共享的大流量应用；
- 需要稳定三网低延迟的核心业务。

2 GB 内存可以运行常见 Linux 服务，但如果同时部署面板、数据库、缓存、Web 服务和监控，内存很快会变紧。40 GB 磁盘也更适合代码、日志和少量业务数据，不适合把它当作文件存储空间使用。

如果你的需求只是部署一个简单网站，HK85 的 CPU 和内存基本够用；如果准备运行复杂面板、容器集群或多个服务，建议直接看 4 GB 或 8 GB 内存的方案。

## 香港机房延迟低，不代表所有运营商都低

“香港 VPS 延迟低”这句话只说对了一半。

香港到华南地区通常有天然的地理优势，广州、深圳、厦门等地的基础延迟可能较低。但 VPS 的实际延迟还取决于：

- 你使用的是电信、联通还是移动；
- 去程和回程是否经过绕行；
- 目标城市的本地出口；
- 机房上游运营商；
- 测试时段是否处于晚高峰；
- 服务器 IP 是否被限速、污染或列入风控名单。

历史 HK85 测试中，移动方向经常被单独拿出来讨论，原因是 CMI 与中国移动网络的关系更直接。部分电信和联通测试虽然也能获得不错数据，但不能据此保证所有地区表现一致。

如果你准备购买香港 VPS，建议至少测试以下几个方向：

1. 本地宽带运营商；
2. 中国电信广州或上海节点；
3. 中国联通北京或上海节点；
4. 中国移动广州或成都节点；
5. 晚上 8 点到 11 点的高峰时段；
6. 下载、上传、TCP 建连和连续丢包率。

单次 Ping 结果只能说明当时的 ICMP 延迟。它不能代表网站首屏速度，也不能代表持续下载速度。

## HK85 的流媒体和 IP 质量怎么样

过去的 HK85 测试中，YouTube、Netflix、Disney+、Amazon Prime Video 等平台的结果并不完全一致。有测试显示 Netflix 只能观看自制内容，部分平台能够识别为香港地区，也有平台无法解锁。

这类结果不能直接套用到每一个新 IP 上。流媒体解锁通常取决于：

- 分配到的 IPv4 地址；
- IP 历史使用情况；
- 流媒体平台的数据库；
- 当前地区识别规则；
- IPv4 或 IPv6 出口；
- 平台是否调整了风控策略。

因此，不建议为了 Netflix、TikTok 或某个特定流媒体平台购买 HK85。服务器 IP 能否解锁并不是搬瓦工套餐页面可以永久保证的配置项。购买后即使机房和套餐相同，不同 IP 也可能出现不同结果。

对于建站而言，IP 质量同样重要。部分第三方测评提到搬瓦工某些香港 IP 的流媒体或代理识别表现一般，但这属于测试样本结论，不应扩展成所有实例的统一表现。
